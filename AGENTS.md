# Scientific research skills

Scientific skills are stored under `.opencode/skills/`.

Before performing a scientific task, inspect the relevant SKILL.md.

Examples:

- Literature search or related-work analysis:
  `.opencode/skills/literature-review/SKILL.md`

- Scientific manuscript writing or revision:
  `.opencode/skills/scientific-writing/SKILL.md`

- Experimental/result analysis:
  use the relevant scientific analysis skill.

Important:
Do not blindly apply a skill.
Read its instructions first and use only the parts relevant to the current task.
