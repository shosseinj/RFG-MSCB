\section{Ablation Study}\label{ablation-study}

We compare three configurations under the common experimental protocol: FAFEM,
FAFEM + MSCB, and FAFEM + RFG-MSCB. The sequence provides protocol-matched references
for the additions made after FAFEM, but it does not measure FAFEM against a no-FAFEM
model under the final protocol or independently isolate all components of RFG-MSCB.

\subsection{Ablation Results}

The sequence begins with FAFEM as the bottleneck enhancement module. The FAFEM-only
configuration contains no multi-scale refinement layers and provides the final-protocol
reference. A no-FAFEM baseline under the final training protocol is not available;
older baseline measurements used a different protocol and are therefore excluded from
this comparison.

Adding a Stage-3 MSCB-lite layer introduces parallel multi-scale refinement without
frequency guidance. This configuration supplies the appropriate reference for the
proposed guided variant because it preserves the multi-scale path while omitting the
cross-level conditioning. The final configuration then adds residual frequency-guided
coupling to that Stage-3 layer. The complete numerical comparison is given in
Table~\ref{tab:ablation}; these results are descriptive and no significance test was
performed.

A single-seed direct frequency-guidance configuration tested the mechanism without
residual coupling. Its Kvasir-SEG result did not exceed the Stage-3 MSCB-lite result
in the paired seed-42 comparison, so this experiment does not isolate the independent
effects of residualization and frequency conditioning.

\subsection{Ablation Interpretation}

The three-seed comparison supports a staged description of the tested configurations.
FAFEM establishes the feature-enhanced reference, MSCB-lite adds multi-scale refinement
at Stage 3, and RFG-MSCB adds adaptive branch modulation to that reference path. The
increment associated with the final coupling is small, so the ablation supports the
feasibility of the proposed refinement but not a claim of broad or statistically
superior improvement. The parameter increase shown in the table is correspondingly
the cost of adding the refinement components rather than evidence that the full
architecture is uniformly preferable.

\subsection{Stage Placement and Generalization}

The placement of the multi-scale refinement layer was also examined exploratorily.
In the final configuration, it is applied only at encoder Stage 3. A
single-seed exploratory all-skip configuration used batch size 32 and the same
learning rate; the available training evidence did not improve relative to the
Stage-3 configuration. Because the run was incomplete and differed in batch size,
it neither isolates placement for RFG-MSCB nor supports a conclusion about optimal
placement.

On the four additional datasets, the change from FAFEM + MSCB to the final guidance
configuration was mixed in the paired seed-42 evidence: mDice decreased on
CVC-ClinicDB and CVC-300 and increased on CVC-ColonDB and ETIS. These comparisons do
not establish uniform cross-dataset improvement. The residual-coupling configuration
with default initialization did not complete training and is therefore excluded from
the quantitative ablation; initialization sensitivity remains a subject for future
work.
