\section{Ablation Study}\label{ablation-study}

We quantify the effect of frequency-guided residual coupling on the FAFEM-enhanced backbone and examine the placement of multi-scale refinement.

The ablation experiments use the same training and evaluation protocol as the final FAFEM + RFG-MSCB model, with variations in the architecture only. Unless otherwise noted, results are reported as mean $\pm$ standard deviation over three random seeds.

\subsection{Effect of FAFEM}

We adopt FAFEM as the bottleneck enhancement module. The FAFEM-only configuration contains no multi-scale refinement layers; its three-seed Kvasir-SEG results are 0.926 mDice, 0.876 mIoU, and 0.025 MAE. A no-FAFEM baseline under the final training protocol is not available; older baseline measurements use a different protocol and are excluded from this comparison.

\subsection{Effect of Stage-3 MSCB-Lite}

Adding a Stage-3 MSCB-lite layer to the FAFEM-enhanced backbone gives the FAFEM + MSCB configuration. MSCB-lite supplies the multi-scale reference without frequency-guided coupling. The three-seed Kvasir-SEG mDice changes from 0.926 to 0.930 (+0.45 percentage points); mIoU changes from 0.876 to 0.881 (+0.55 percentage points), and MAE decreases slightly, from 0.025 to 0.024. This configuration serves as the reference for the frequency-guided variant.

\subsection{Effect of Residual Frequency-Guided Coupling}

The final FAFEM + RFG-MSCB model adds residual frequency-guided coupling to the Stage-3 multi-scale layer. This is the principal architecture change relative to the FAFEM + MSCB configuration. Using the underlying three-seed values, Kvasir-SEG mDice changes from 0.930 to 0.931 (+0.08 percentage points), mIoU changes from 0.881 to 0.883 (+0.12 percentage points), and MAE changes from 0.024 to 0.024 (-0.001). These are descriptive differences; no significance test was performed.

A single-seed direct frequency-guidance configuration tested the mechanism without residual coupling; its Kvasir-SEG result did not exceed the Stage-3 MSCB-lite result in that paired seed-42 comparison. Because it is single-seed, this result does not isolate the independent effect of residualization.

\subsection{Stage Placement Analysis}

The placement of the multi-scale refinement layer is analyzed experimentally. In the final FAFEM + RFG-MSCB configuration, the layer is applied only at encoder Stage 3. This placement was selected based on observed results rather than theoretical assumptions.

A single-seed exploratory all-skip configuration used batch size 32 and the same learning rate; the available training evidence did not improve relative to the Stage-3 configuration. However, this comparison is limited by incomplete training and the batch-size mismatch, so we cannot draw general conclusions about optimal placement from it. Future work could systematically ablate stage placements with more rigorous statistical verification.

\subsection{Ablation Discussion}

The three-seed ablation gives the following sequence:
\begin{enumerate}
\item FAFEM provides the verified feature-enhanced baseline (0.926 mDice on Kvasir-SEG).
\item Adding MSCB-lite at Stage 3 changes mDice to 0.930, a +0.45 percentage-point difference relative to FAFEM.
\item Incorporating residual frequency-guided coupling changes mDice to 0.931, a +0.08 percentage-point difference relative to FAFEM + MSCB; this is a descriptive three-seed result, not a significance claim.
\end{enumerate}

The parameter count increases from 29.40 M for FAFEM to 30.00 M for FAFEM + MSCB and 30.10 M for the final FAFEM + RFG-MSCB model.

\subsection{Generalization Evaluation}

On the four additional datasets, the final RFG-MSCB change relative to FAFEM + MSCB is mixed: paired seed-42 mDice decreases on CVC-ClinicDB and CVC-300 and increases on CVC-ColonDB and ETIS. These comparisons do not establish uniform cross-dataset improvement.

The residual-coupling configuration with default initialization did not complete training, so it is excluded from the quantitative ablation. Future work may examine sensitivity to initialization strength in more detail.
